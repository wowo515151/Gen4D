# Gen4D

[Open the Gen4D field explorer](https://wowo515151.github.io/Gen4D/)

An experimental, offline-first scalar field explorer. Serve this directory with a local HTTP server and open its address in a WebGL-capable browser; JavaScript modules may not load from a `file:` URL. Drag to rotate or scroll to zoom. For keyboard access, focus the 3D visualization and use the arrow keys to rotate and plus or minus to zoom. Use the left panel to choose a field, change parameters and rendering, and control time. Expand a wave component to edit its x/y/z wave-vector coefficients, relative amplitude, and phase offset; the sum stays normalized to the selected amplitude.

The catalog contains ten traveling, standing and interfering wave patterns for each of three PDE families. The patterns are normalized superpositions of plane waves. The Klein–Gordon and free Schrödinger equations, plane-wave solutions and dispersion relations were checked against Likharev, [“The Klein–Gordon and Relativistic Schrödinger Equations,” §9.5](https://phys.libretexts.org/Bookshelves/Quantum_Mechanics/Essential_Graduate_Physics_-_Quantum_Mechanics_%28Likharev%29/09%3A_Elements_of_Relativistic_Quantum_Mechanics/9.05%3A_The_Klien-Gordon_and_Relativistic_Schrodinger_Equations); the vacuum electromagnetic wave equation and wave speed were checked against Staelin, [“Electromagnetic Waves in the Time Domain,” §2.2](https://phys.libretexts.org/Bookshelves/Electricity_and_Magnetism/Electromagnetics_and_Applications_%28Staelin%29/02%3A_Introduction_to_Electrodynamics/2.02%3A_Electromagnetic_waves_in_the_time_domain). The quantum display shows only the real component of a complex free-particle wavefunction; its displayed second-order-in-time real-part PDE and the scalar superpositions are derived from the cited equations. The electromagnetic display is a scalar solution to the vacuum wave equation, not a full vector field satisfying all of Maxwell’s equations. These idealized examples are not physical predictions. Local numerical, catalog and geometry tests pass; a browser smoke check exercised field selection, tubular multi-level rendering, pause, reset, and keyboard orbit/zoom. Earlier browser viewport overrides at 320×700 and 390×844 found no horizontal overflow. In a representative 13³ Klein–Gordon three-dimensional weave with four levels, four extracted surfaces had 43,704 per-triangle edge segments and 22,716 unique tube edges after deduplication (48% fewer tube instances). In local desktop browser checks, changing to four tubular levels took 352–489 ms from control action to visible status; this coarse interval did not demonstrate a cold-start speedup and is not a mobile or GPU benchmark.

The Three.js r128 runtime and OrbitControls were copied from an existing local project, and the isosurface and material modules come from the local three-viz library. They are distributed under MIT terms; see LICENSE and THIRD-PARTY-LICENSES.txt. No network assets are needed to run the site.

Run `npm test` for the numerical and geometry checks.
